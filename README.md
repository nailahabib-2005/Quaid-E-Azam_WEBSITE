# Quaid-e-Azam Website

A responsive educational website developed as a web development project. The website presents information about Quaid-e-Azam and provides different sections related to academic programs, admissions, faculty, funding, and research.

## 🌐 Live Website

[View Live Website](https://nailahabib-2005.github.io/Quaid-E-Azam_WEBSITE/)

## 📌 Project Overview

This project is a multi-page website created using HTML and CSS. It was developed to practice website structure, navigation, page design, styling, and organizing information across multiple web pages.

The website contains different sections and pages that allow users to navigate through academic and university-related information.

## ✨ Features

* Multi-page website
* Home page
* Academic information
* Admission section
* Faculty section
* Research section
* Funding information
* Responsive page structure
* Navigation between different pages
* Image-based content
* Consistent styling using CSS

## 📄 Website Pages

The project includes the following main pages:

* `index.html` — Home page
* `acadmic.html` — Academic information
* `admission.html` — Admission information
* `faculty.html` — Faculty information
* `funded.html` — Funding information
* `research.html` — Research information
